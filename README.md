# Ashish Dubey — Portfolio Website

A responsive, single-page portfolio for Ashish Dubey, focused on SAP BTP, SAP platform administration, cloud architecture, security, integrations, and DevOps.

## Publish

This is a static website. The entry point is `index.html`; no build step or package installation is required.

### GitHub
1. Open the `ashish-portfolio` repository.
2. Select **Add file → Upload files**.
3. Upload `index.html` from this folder and commit it to the `main` branch.

### Vercel
The Vercel project is linked to this GitHub repository. Once `index.html` is committed to `main`, Vercel can build and deploy the site from that branch; subsequent pushes to the production branch trigger deployments automatically.
